# Patches for the game repos

This session has read-only access to `cktang88/3d-world-objects` and `cktang88/voxel-castle-defense`,
so changes to them are kept here as `git format-patch` files. To apply one:

```bash
cd 3d-world-objects && git checkout -b air-mode && git am ../fastrender/patches/3d-world-objects-000*.patch   # in order: 0001 .. 0006
```

| Patch | What | Verified |
|---|---|---|
| `3d-world-objects-0001-air-mode.patch` | Base Apple Silicon boots in `quality=low` (Pro/Max in `high`); the interior cube shadow is cached (re-rendered on room change and every 30 frames, instead of 6 passes every frame); dynamic resolution also runs on low | `tsc --noEmit` ok; `npm run qa:changed`: interior 14/14 passed. Not run on a real Air. |
| `3d-world-objects-0002-three-r187.patch` | three 0.170 -> **0.187.0** (+ @types/three 0.187.0); apply after 0001. PMREM env blend rebuilt on cube targets (`CubeUVReflectionMapping` is gone), CSM `getExtendedBreaks()` replaced, `vColor` is vec4 in shader patches, `RGBELoader`->`HDRLoader`, `PCFSoftShadowMap`->`PCFShadowMap`, `Clock`->`Timer`, one test fixed for the r185 `Box3` change | `tsc --noEmit` ok; `npm run build` ok; `npm run qa`: 260/260 (interior 14/14); headless Chromium: world, museum and ~20 labs compile all shader programs with no errors and render. Not run on real GPU/Air; visuals differ slightly (new PMREM, energy-conserving PBR, Sky/RoomEnvironment changes). |
| `3d-world-objects-0003-instance-cull-hints.patch` | Apply after 0002. `userData.frInstanceCull` on the vehicle fleet's InstancedMeshes (`true`) and on the window parts (the radius an instance stays within: geometry radius + the opening's diagonal), so FastRenderer draws only the instances in view (docs/notes/gpu-cost.md). three's WebGLRenderer ignores the field: no change in the browser | `git apply --check` + `patch -p1` on 0001 + 0002; the node run of the patched game: 3.54 M of 5.07 M triangles per frame become eligible, 1.14 M drawn. Hand-assembled mail (this session cannot commit in the game repo); not run on a GPU. |
| `3d-world-objects-0004-far-lods.patch` | Apply after 0003. Far LODs built at load with the game's vendored meshoptimizer: the blocks' merged static meshes get a twin within 6 cm (about a third of the triangles) shown beyond 70 m (`src/nyc/chunkLod.ts`), cars beyond 90 m use their far LOD simplified within 7 cm (`vehicleFleet.ts`). Same materials, no new shader; also in the browser. After review: the version of a merged mesh that is not shown has a no-op `raycast` (three's Raycaster ignores `visible`), and a car's distant-LOD flag is decided on every level (`fleetDistant`), not only on the far one | `git am` on a fresh copy after 0001-0003, and 0005 after it (`world-game.sh`); `tsc --noEmit`: no new errors; `npm run qa`: 264 passed (new `tests/chunk-lod.test.ts`; with 0005 and the review fixes: 268); node run of the patched game: triangles in view 2.25 M -> 1.75 M (docs/notes/gpu-cost.md). Not run on a GPU. |
| `3d-world-objects-0005-static-subtrees.patch` | Apply after 0004. `src/static.ts`: every part of a placed block (parked cars, sidewalk models, merged meshes, lamp markers; not the steam puffs) is frozen: its matrices are computed once and three's per-frame `updateMatrixWorld` no longer descends into it (14,400 of 24,000 objects). Recomputed when a child is added below it (`Object3D.add` wrapped), when it or an ancestor moves, on `touch(o)`; a per-frame audit of 256 objects is the net under hand-written transforms. `STATIC.on` / `?static=0` switches it off. Also in the browser | `git am` on a fresh copy after 0001-0004 (`world-game.sh`); `tsc --noEmit`: no new errors; `npm run qa`: 268 passed (new `tests/static.test.ts`); node run of the patched game: `scene.updateMatrixWorld` 4.2-4.6 -> 0.75-1.0 ms, `render()` 13-14 -> 7.3-8.8 ms, every matrix equal to three's plain walk on every frame checked, also while walking through streaming blocks (docs/notes/three-programs.md "Static transforms"). Not run on a GPU / the Air. |
| `3d-world-objects-0006-cluster-marks.patch` | Apply after 0005. `bake()` marks every merged block mesh `userData.frClusters = true` (fastrender's cluster LOD, docs/notes/clusters.md; off by default). While the renderer's clusters are on (`globalThis.__frClusters`, set by FastRenderer), `chunkLod.ts` builds and shows no far twins: the renderer picks a level per cluster. WebGLRenderer ignores the field and the global is absent in the browser: no change there | `git am` on a fresh copy after 0001-0005 (`world-game.sh`); `npm run qa`: 268 passed (`tests/chunk-lod.test.ts` extended: marks, no twins with the global set, twins without); `tsc --noEmit`: no new errors. Not run on a GPU here; CI renders the golden camera with clusters on. |
